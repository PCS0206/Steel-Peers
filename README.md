# Steel Peers

호이4(Hearts of Iron IV) 느낌의 **싱글플레이 웹 지도 전략 게임** 초안. AI 국가들과 함께 진행한다.
빌드 도구·의존성 없음 — `index.html`을 브라우저로 열면 실행된다.

## 플레이
1. **새 게임** → 지도에서 플레이할 국가를 클릭
2. `Space`로 시작/일시정지, `1~3`으로 속도 조절
3. 좌클릭: 지역 선택 / 우클릭: 선택한 사단 이동 / 드래그: 지도 이동 / 휠: 확대·축소
4. **생산 라인**을 추가해 사단을 계속 뽑고, 국경을 맞댄 나라에 선전포고 → 지역 점령
5. 승리: 전체 육지의 60% 점령 또는 최후의 1국. 패배: 멸망

## 구현된 것
- 시드 기반 절차적 지도 (보로노이 지역 ~150개, 노이즈로 대륙/바다)
- 6개 국가, 지역 소유·산업(PP 생산량)·수도
- 일 단위 시뮬레이션, 일시정지/3단계 속도
- 반복 생산 라인(PP → 사단), 부대 이동(지역당 3일), 교전(방어 보너스)·점령
- 선전포고 / 강화 제안(AI가 전력 비교로 수락 여부 결정) / 휴전 기간
- AI: 생산, 약한 이웃에 선전포고, 가장 가까운 목표로 부대 파견, AI끼리 전쟁·강화

## 구조
| 파일 | 역할 |
|---|---|
| `js/map.js` | 지도 생성, 지도 이미지 렌더링 |
| `js/game.js` | 규칙(경제·이동·전투·점령·외교). DOM 의존 없음 |
| `js/ai.js` | AI 의사결정 |
| `js/ui.js` | 카메라, 입력, 패널, 캔버스 그리기 |
| `tools/simulate.js` | 헤드리스 시뮬레이션 (`node tools/simulate.js <seed> <days>`) |
