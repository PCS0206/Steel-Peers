# Steel Peers

호이4(Hearts of Iron IV) 느낌의 **싱글플레이 웹 지도 전략 게임** 초안. AI 국가들과 함께 진행한다.
순수 정적 사이트(서버 불필요, 런타임 의존성 없음). 개발 중에는 `index.html`을 그대로 열고, 배포용은 `npm run build`로 `dist/`를 만든다.

## 플레이
1. **새 게임** → 지도에서 플레이할 국가를 클릭
2. `Space`로 시작/일시정지, `1~3`으로 속도 조절
3. 좌클릭·탭: 지역 선택 / 우클릭·길게 누르기·이동 모드: 사단 이동 / 드래그: 지도 이동 / 휠·핀치: 확대·축소
4. **생산 라인**을 추가해 사단을 계속 뽑고, 국경을 맞댄 나라에 선전포고 → 지역 점령
5. 승리: 전체 육지의 60% 소유, 또는 남은 모든 국가가 내 동맹. 패배: 멸망
6. 💾/📂로 저장·불러오기, 30일마다 자동 저장(새로고침 후 `이어하기`)

## 구현된 것
- **지도**: 시드 기반 절차적 생성(보로노이 지역 ~150개), 지형 5종(평원/숲/구릉/산악/늪)
- **시간**: 일 단위 시뮬레이션, 일시정지/3단계 속도
- **지형**: 이동 시간·방어 보너스, 기갑은 험지에서 공격 약화, 산악보병은 구릉·산악에서 강함
- **사단 종류**: 보병/기갑/산악보병(PP·인력·속도·지형 보정이 다름). 부대는 혼성 편제, 종류별 분리 가능
- **공장·장비 경제**: 공장은 지역에 속한다(점령당하면 생산 중단, 할양받으면 획득)
  - 민수 공장 → PP(하루 1 + 0.6×공장 수) → **공장 건설**(100 PP, 지역 슬롯 = 산업 + 1)
  - 군수 공장 → 보병장비/전차 **생산 라인에 할당**(조정 가능) → 장비 비축
  - **사단 훈련**: 시작 시 장비·인력을 소모하고 10~16일 훈련 후 수도에 편성(반복 라인). 장비·인력이 모자라면 대기
  - 보병/산악보병 = 보병장비 40, 기갑 = 전차 25. 취소하면 장비·인력 환급
  - AI도 공장을 짓고 장비 할당을 조정
- **보급·조직도**: 아군 지배지에서 2지역 넘게 벗어나면 보급 끊김 → 조직도·병력 감소, 전투력 저하. 휴식 시 회복
- **안개(시야)**: 내/동맹 영토와 부대 주변만 보이고, 시야 밖 적 부대·전력은 숨김 (AI는 안개 영향 없음)
- **점령 vs 소유**: 점령하면 지배권만 이동(줄무늬로 표시). 강화 때 **점령지 요구**로 소유권 이전. 지배 지역이 없으면 항복 → 점령국에 합병
- **전선(호이4식 자동 전투)**
  - **🖊 전선 그리기**: 적과 맞닿은 접경 지역을 **드래그**(또는 탭)해서 전선을 직접 긋는다. 그린 구간만 전선이 되고, 점령하면 앞으로 전진·밀리면 뒤로 후퇴(길이 상한 있음). (접경 전체를 자동으로 잡는 자동 전선도 가능)
  - **➜ 공격 화살표**: 공격 전선에서 전선 위 → 적 지역을 따라 드래그하면 진격 목표가 된다. 사단은 화살표 목표를 순서대로 공략하고, 달성하면 화살표가 사라진다 (전선당 최대 4개)
  - ⚔ 공격: 접경에 집결 → 같은 지역의 사단이 합산 전력으로 함께 진격 (보급·조직도·시야 반영). 🛡 방어: 위협에 비례해 접경에 분산, 침투한 적에게 집결, 국지 우세 시 역공
  - 재배치는 아군 지배 지역으로만 이동(적 영토를 가로지르지 않음). 신규 사단 자동 배치, 일괄 배치, 모드 전환, 해산. 직접 이동 명령을 내리면 해당 사단은 전선에서 빠짐
- **적국 표시**: 전쟁 중인 국경은 지도에서 빨간 선, 적국 이름은 `⚔` + 빨간 글씨, 적 수도 별은 빨강, 동맹국은 `🤝` + 초록 글씨, 상단바·세계 목록에도 표시
- **알림**: 중요한 일은 화면 중앙 팝업으로 알리고 게임을 자동 정지(확인하면 이전 속도로 재개) — 선전포고를 받음, 동맹 때문에 참전/새 적 참전, 수도 함락. 그 외(강화·동맹·공장 완공·AI 간 전쟁 등)는 상단 토스트. 선전포고·동맹 탈퇴는 실행 전에 확인 창(참전하는 동맹 미리 표시)
- **외교**: 선전포고, 백색 강화/점령지 요구, 동맹(최대 3국, 자동 참전), 탈퇴, 휴전 기간
- **AI**: 혼성 생산, 약한 이웃 공격, 보급 범위 내 목표 선정, AI끼리 동맹·전쟁·강화
- **저장/불러오기**: `localStorage`. 시뮬레이션이 일 단위 시드라 불러온 뒤에도 결과가 동일
- **터치**: 탭 선택, 길게 누르기·이동 모드로 명령, 드래그 이동, 핀치 줌, 모바일 레이아웃

## 개발
```
npm test            # 로직 테스트 (결정성, 저장/불러오기, 동맹, 강화, 시야 등)
npm run simulate -- 3 500   # 헤드리스 시뮬레이션: seed, days
npm run build       # dist/ 생성 (app.js 하나로 합침 + 캐시 해시)
npm run serve       # dist/를 http://localhost:8000 으로 확인
```
`dist/`는 정적 파일뿐이라 GitHub Pages / Netlify / Cloudflare Pages 등에 그대로 올리면 된다.

## 구조
| 파일 | 역할 |
|---|---|
| `js/map.js` | 지도·지형 생성, 지도 이미지 렌더링(안개·점령 줄무늬) |
| `js/game.js` | 규칙(이동·전투·보급·점령·외교·저장). DOM 의존 없음 |
| `js/economy.js` | 공장·PP·장비·훈련·건설 (DOM 의존 없음) |
| `js/fronts.js` | 전선 계산·자동 배치/진격 (플레이어용 전선 AI, DOM 의존 없음) |
| `js/ai.js` | AI 국가 의사결정 |
| `js/ui.js` | 카메라, 입력(마우스/터치), 패널, 캔버스 |
| `tools/` | 테스트·시뮬레이션·빌드 스크립트 |
